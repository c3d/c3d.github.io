## First Graphical Emacs on macOS

When Apple released macOS with only a text-only version of Emacs (working only in Terminal app), I was disappointed.

### Taking Initiative

I waited a couple of months, thinking someone else would fix this. But it didn't happen. So I:
- Took an old NeXT port
- Adapted it to the Aqua graphical interface
- Added macOS-only niceties like transparent windows
- Published it on SourceForge

### Impact

This port provided the first graphical Emacs experience on macOS Aqua, filling an important gap for Mac-using developers who relied on Emacs.

### Legacy

By the time Emacs 23 was out, there were several forks and alternative implementations. Soon, maintaining a separate branch became unnecessary, since the primary version had integrated native graphical support for macOS.

This port is now obsolete, but it served its purpose: getting Emacs users productive on the new macOS platform while the official port caught up.

### Philosophy

An example of: "If nobody else will fix it, maybe I should."
