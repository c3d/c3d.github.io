## BASIC extension for the Sinclair ZX Spectrum

- First published program — graphic BASIC extensions for the ZX Spectrum
- Windows, ellipses, clipping, flood fill (including 8×8 patterns)
- ~3.5KB of Z80 assembly; distributed by Valric-Laurene
- Name collided with Sinclair’s own Spectrum+ computer release
