## Viral Games & Development System

Created HPDS (HP Development System) and several viral games for HP-48 calculators.

### HPDS - HP Development System

Evolution from SATAS (assembler for HP-28C, HP-28S, HP-48SX) into a complete development system for HP calculators. Used to create numerous programs and games.

### PacMan for HP48 - First Viral Calculator Game

**Innovation:** First use of HP48 hardware scroll

Released initially as an assembly-only program with HPDS 1.0, later converted to HP-48 library with HPDS 2.0 in 1991. According to Paul Courbis, this was the first game to use the hardware scroll of the HP-48 calculator, making the game very fluid.

**Viral Spread:** Being one of the very first games for the HP-48, PacMan quickly became popular, taking advantage of the HP48's built-in infrared networking to spread virally—hopping from machine to machine, spreading to other countries including the United States. I received letters from all over the world.

### Tetris for HP48 - Tutorial Game

Demo game for HPDS written in 1991. A simple Tetris clone intended primarily as a tutorial and demo for what could be done with a cross-development tool for HP48.

### Lemmings for HP48 - Pushing the Envelope

**Ambition:** Version 3.0 of HPDS included a clone of Lemmings, complete with an editor to create new levels. Source code dated from 1993.

**Technical Challenge:** Pushed the limits of the calculator in memory and in the number of lemmings animated on screen with a meager 2MHz 4-bit CPU.

### Space Invaders - The Game I Never Wrote

Someone wrote a Space Invaders game and put my name in the credits! A friend said "Your Space Invaders is really not as good as your other games." I had never written it. I'm still hoping it was a kind of homage to my other games. I never knew who the real author was.

**Quote:** *"The first games to use the HP-48 hardware scroll"* - P. Courbis on viral calculator games
