## HP Development System for HP calculators

- SATAS — assembler for the HP-28C, HP-28S, and HP-48SX
- Evolved into HPDS (HP Development System) for any kind of HP calculator program, not only assembly
- Used to create games for these calculators
- Source for HPDS was lost; a MacOS 7 binary for HPDS 3.0 and game sources remain
