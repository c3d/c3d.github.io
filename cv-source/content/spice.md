## Remote Visualization & Streaming

Part of the Spice team at Red Hat, focusing on remote visualization which is essential to Red Hat's virtualization offering.

### Smart Streaming in SPICE

Implemented smart streaming in the SPICE remote viewer (Cyrix), a highly capable connected camera. Enhanced the dual-core ARM + 88-bit real-time system for remote display capabilities.

### Remote Display Protocol

SPICE (Simple Protocol for Independent Computing Environments) provides remote access to virtual machines with:
- High-quality graphics streaming
- Multi-monitor support
- Audio redirection
- USB redirection
- Optimized for LAN and WAN
