## Ray-Tracing Meets Auto-Stereoscopy

3DIVART is my attempt to adapt ray-tracing and ray-marching shaders from locations such as ShaderToy for use on auto-stereoscopic screens using Tao3D.

### Result

3D interactive visual art—something that you see in 3D, but that is perfectly synthetic. Art that exists only in the mathematics of the rendering algorithms.

### Techniques

**Ray-Marching:** Highly detailed rendering technique which can compute:
- Realistic shadows
- Complex lighting
- Scenes with a very large number of visible elements
- Real-time on GPU

**Interactive Elements:** Unlike static shader demos, these pieces are interactive, responding to user input and running in true stereoscopic 3D on specialized displays.

### Sources

Most 3DIVART pieces are obviously derived from work on ShaderToy, but I also started creating a few pieces of my own, exploring the intersection of:
- Mathematical beauty
- Real-time rendering
- Stereoscopic display
- Interactive art

### Philosophy

Exploring strange forms of art at the intersection of technology and visual experience. Creating experiences that can only exist in the digital realm.
